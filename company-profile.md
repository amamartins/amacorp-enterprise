# AMACorporations

AMACorporations is a fictional enterprise created as a cybersecurity
homelab environment for studying enterprise IT, networking, security
operations, offensive security, and incident response.

## Industry
Technology / Professional Services

## Employees
~100 simulated users

## Departments
- Executive
- Human Resources
- Finance
- IT
- Security
- Sales
- Marketing

## Primary Objectives

- Build and secure an enterprise network
- Simulate realistic security incidents
- Monitor enterprise activity
- Investigate attacks
- Develop detection and response capabilities
- Practice enterprise security administration
